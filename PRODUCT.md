# Product

## Register

brand

## Users

Visitors reviewing Seiya's web presentations, software projects, and learning record on desktop or mobile.

## Product Purpose

Present a clear, credible personal technology portfolio and make it easy to browse projects, open web presentations, and use the existing like, comment, and account features.

## Brand Personality

Clear, thoughtful, technical.

## Anti-references

Avoid generic AI SaaS styling, large purple-blue gradients, excessive glass effects, nested cards, decorative motion, and interfaces that resemble an admin dashboard.

## Design Principles

- Let the work lead; controls support discovery instead of competing with it.
- Use hierarchy and spacing before decoration.
- Keep interaction patterns consistent and obvious.
- Preserve readable, touch-friendly layouts at narrow widths.
- Prefer restrained, reversible changes over visual reinvention.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, 44px touch targets for primary controls, readable text sizing, natural wrapping, and reduced-motion support.
